3. Test Suite Durumu

İlk test çalıştırmasında corpus parser smoke test başarısız oldu.

Hata:

mwxml.errors.MalformedXML: <siteinfo> tag not found when processing a <mediawiki>

Sebep:

Production parser smoke testinde kullanılan tiny XML fixture, mwxml için geçerli bir MediaWiki dump yapısına sahip değildi. mwxml, <mediawiki> içinde <siteinfo> bekliyor.

Yapılan fix:

  1. tests/test_corpora_phase1.py içindeki tiny XML fixture’a geçerli bir <siteinfo> bloğu eklendi.
  1. src/transfer_vs_relearning/corpora/extract.py içinde page.namespace is None durumu güvenli hale getirildi.

Kod değişikliği mantığı:

Eski:
namespace = int(getattr(page, "namespace", -1) or -1)

Yeni:
namespace_value = getattr(page, "namespace", -1)
namespace = -1 if namespace_value is None else int(namespace_value)

Bu değişiklik production parser yolunu zayıflatmadı. Aksine gerçek mwxml davranışına karşı daha sağlam hale getirdi.

Final test sonucu:

59 passed in 2.77s
compileall ok

Skip yok. Bu çok iyi bir durum çünkü HU ortamında hem Torch hem mwxml/mwparserfromhell çalışır durumda doğrulandı.
