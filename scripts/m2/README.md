# M2 workflow archive

These are preserved pre-M2, Qwen pilot and Turkish-bridge tools. They do not define the new
M2-A/M2-B sibling implementation by themselves.

Use filename families as the local index:

- `*pre_m2*`: historical pre-M2 contracts, controls and checkpoint waves;
- `*qwen_m2_m3*`: completed Qwen Wikipedia-only pilot family;
- `*turkish_bridge*` and `*qwen_bridge*`: bridge corpus/evaluation work;
- `prepare_*`, `build_*`, `materialize_*`, `freeze_*`: preparation;
- `evaluate_*`, `compare_*`, `analyze_*`, `summarize_*`, `finalize_*`: measurement and analysis;
- `submit_*.sh`: historical bounded launch wrappers.

Current sibling-arm work begins with the study manifest and a reviewed Luna packet, not by
selecting an old launcher from this directory.
