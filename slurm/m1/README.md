# M1 Slurm archive

This directory preserves M1 acquisition, training, evaluation and recovery launchers. Locate a
known family by filename prefix (`acquire_`, `prepare_`, `preflight_`, `train_`, `eval_`, `audit_`,
`summarize_`) and its experiment token (`retention`, `dose_pareto`, `provenance_screen`,
`form_generalization`, `qwen_scale`, or `smollm`).

Do not browse this directory to infer a next job. These launchers remain historical implementation
artifacts and require a current contract plus explicit execution authorization.
