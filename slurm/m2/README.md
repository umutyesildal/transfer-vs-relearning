# M2 Slurm archive

This directory preserves three distinct historical families:

- `*pre_m2*`: pre-M2 control and checkpoint work;
- `*qwen_m2_m3*`: completed Qwen pilot work;
- `*turkish_bridge*` and `*qwen_bridge*`: bridge preparation, training and evaluation.

They are evidence-backed launchers, not the new M2-A/M2-B sibling pipeline. A future study-level
Slurm adapter belongs under `slurm/study/` only after the corresponding contract is frozen.
