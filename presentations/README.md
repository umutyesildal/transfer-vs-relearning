# Presentations

This directory preserves authored presentation files, rendered evidence, and the build sources that
were previously spread across the workspace root, `outputs/`, `tmp/`, and `.tmp/`.

- `legacy/max_meeting_progress/`: the August 2026 meeting deck and seven rendered slides;
- `legacy/research_updates/`: earlier Qwen/M1/M2-M3 presentation files;
- `source/`: reusable authoring scripts, source notes, templates, assets, and layout evidence.

Generated inspection streams and large render intermediates may remain local and Git-ignored. The
pre-migration source paths and relocation rules are recorded in
`documentation/migration/MIGRATION_LEDGER.json`.
