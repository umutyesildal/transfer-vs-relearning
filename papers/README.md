# Local Reference Library

This directory is part of the lossless workspace migration. Authored literature notes and maps are
tracked in Git. The collected third-party PDF files are copied into the local monorepo workspace
and covered by the private migration inventory, but are intentionally Git-ignored until their
redistribution rights and the repository's Git LFS policy are decided.

Do not delete the original `implementation/papers/` library after cloning this repository. A
separate, verified reference-library retention decision is required first.

The current authored literature map is
`documentation/THESIS_RELEVANT_PAPERS_MASTER_MAP_TR.md`.
