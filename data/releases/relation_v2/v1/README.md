# Relation V2 Dataset Release V1

This release is generated by `generate_relation_v2_dataset.py` from the frozen profiles and
accepted relation assignments.

Dataset contract:

- subjects: 5,000
- facts: 25,000
- relations: `profession`, `born_in`, `lives_in`, `field_of_study`, `works_in_industry`
- English training rows: 120,500
- Turkish repetition rows: 60,235, Branch B only
- historical `studied_at` and `works_at`: absent
- new-relation frequency buckets: subject popularity only

The complete generated dataset is 90 MB and is intentionally not duplicated as raw JSONL in
Git. `manifest.json` freezes every full-output hash. Any target checkout can reproduce the full
tree with:

```bash
python generate_relation_v2_dataset.py
```

The immediately required 10-subject direct-aware acquisition gate is versioned in full:

- subjects: 10
- facts: 50
- train rows: 350
- rows per fact: 7
- composition: 3 declarative, 2 QA, 2 direct
- held-out validation rows: 50
- exact-prefix probes: 50
